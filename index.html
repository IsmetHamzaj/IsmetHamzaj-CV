About me

From HTML basics to production apps

I'm a full-stack developer and Computer Science student at University "Ukshin Hoti" in Prizren. I started with HTML, CSS and JavaScript in 2019 and moved on to Node.js, Express, MySQL, and then React and the MERN stack.
